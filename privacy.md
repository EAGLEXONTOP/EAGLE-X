# Privacy Policy - Eagle X

Last Updated: 2025

Eagle X bot collects and stores only necessary data to function properly.

**Data We Collect:**
- User IDs
- Server IDs
- Command usage data

**How We Use Data:**
- To provide bot features
- To improve the bot
- For moderation purposes

We do not sell your data to anyone.  
Data is stored securely and only accessible to the developers.

You can request data deletion by contacting us on our support server.
